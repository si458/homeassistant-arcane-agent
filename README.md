# Arcane Agent for Home Assistant

This repository provides a Home Assistant app that runs the official Arcane Agent
in direct mode.

## Install

1. In Home Assistant, open **Settings → Apps** (called **Add-ons** in older
   versions) and open the app store menu.
2. Add this repository:
   `https://github.com/traukainehm/homeassistant-arcane-agent`
3. Install **Arcane-Agent** from the app store.
4. Follow the configuration and setup instructions in
   [the app documentation](arcane-agent/DOCS.md).

The app image is built by Home Assistant for the host architecture. The app
requires a Home Assistant installation with Supervisor.
